{% extends "docs_default.html" %} {% block title %} {{ _("%(site)s - OAuth2") }} {% endblock %} {% block content %} {% filter markdown %} # {% trans %}OAuth2{% endtrans %} {% trans site='SITE_NAME' | app_config %}The OAuth2 authorization flow is used to enable users to authorize third-party applications to access their {{ site }} account without having to provide their login information to the application.{% endtrans %} {% trans %}This page explains how to obtain API application keys, how to prompt a user for authorization, and how to obtain and use access tokens.{% endtrans %} ## {% trans %}Step 1: Create your Application{% endtrans %} {% trans site='SITE_NAME' | app_config %}In the [apps tab of {{ site }} settings](/settings/apps), fill in and submit the form to request new API keys. You will need:{% endtrans %} * {% trans %}an application name{% endtrans %} * {% trans %}a Redirect URI, or a comma-separated list of redirect URIs. May not use HTTP unless using localhost (use HTTPS instead).{% endtrans %} * {% trans %}a brief description of what your application is intended to do{% endtrans %} {% trans %}Don't worry too much about accuracy; you will be able to change all of these later.{% endtrans %} {% trans %}DO NOT reveal your Client Secret. Anyone with your Client Secret will be able to pretend to be you. You are responsible for keeping your Client Secret a secret!{% endtrans %} ## {% trans %}Step 2: Prompt Your User for Authorization{% endtrans %} {# Translators: text between backticks (`...`) is code or an address: keep it exactly as it is on this page. #}{% trans %}Send your user to `https://ruqqus.com/oauth/authorize`, with the following URL parameters:{% endtrans %} * {% trans %}`client_id` - Your application's Client ID{% endtrans %} * {% trans %}`redirect_uri` - The redirect URI (or one of the URIs) specified in your application information. Must not use HTTP unless using localhost (use HTTPS instead).{% endtrans %} * {% trans %}`state` - This is your own anti-cross-site-forgery token. We don't do anything with this, except give it to the user to pass back to you later. You are responsible for generating and validating the state token.{% endtrans %} * {% trans %}`scope` - A comma-separated list of permission scopes that you are requesting. Valid scopes are: `identity`, `create`, `read`, `update`, `delete`, `vote`, and `guildmaster`.{% endtrans %} * {% trans %}The `delete` scope removes an item from the site; what it removes more than five minutes after the item was written stays in the public Log as Anonymous. Taking a name off instead ("Remove my name") and the History tools are the site's own and are not offered to apps.{% endtrans %} * {% trans %}`permanent` - optional. Set to `true` if you are requesting indefinite access. Omit if not.{% endtrans %} {% trans site='SITE_NAME' | app_config %}If done correctly, the user will see that your application wants to access their {{ site }} account, and be prompted to approve or deny the request.{% endtrans %} ## {% trans %}Step 3: Catch the redirect{% endtrans %} {% trans site='SITE_NAME' | app_config %}The user clicks "Authorize". {{ site }} will redirect the user's browser to GET the designated redirect URI. The following URL parameters will be included, which your server should process:{% endtrans %} * {% trans %}`code` - a **single-use** authorization code.{% endtrans %} * {% trans %}`state` - The state token from earlier.{% endtrans %} {% trans %}Validate the state token. How you do this is up to you.{% endtrans %} ## {% trans %}Step 4: Exchange code for access token{% endtrans %} {% trans %}Make a POST request to `https://ruqqus.com/oauth/grant`. Include the following form parameters:{% endtrans %} * {% trans %}`client_id` - Your application's Client ID{% endtrans %} * {% trans %}`client_secret` - Your application's Client Secret{% endtrans %} * {# Translators: the word in quotes is a value the application sends as it is: keep it in English. #}{% trans %}`grant_type` - Set to the word "code"{% endtrans %} * {% trans %}`code` - The `code` parameter that was given to you in the previous step.{% endtrans %} {% trans %}Python example:{% endtrans %} 
	import requests
	import pprint

	code=request.args.get("code")

	headers={"User-Agent": "Porpl Reader v1 by @captainmeta4"}
	url="https://ruqqus.com/oauth/grant"
	data={"client_id": my_client_id,
		  "client_secret": my_client_secret,
		  "grant_type": "code",
		  "code": code
		  }

	r=requests.post(url, headers=headers, data=data)

	pprint.pprint(r.json())
{% trans %}If everything is good, we will respond with the following (example) JSON body:{% endtrans %}

	"scopes": 				#Comma-separated list of scopes included in authorization
	"expires_at": 			#Unix epoch integer time at which access token expires
	"token_type": "Bearer"
	"refresh_token":		#This key is omitted in temporary authorizations
	}
{% trans site='SITE_NAME' | app_config %}Store the access and refresh tokens. You should also store expiration timestamp and the scopes list, so that you can avoid sending invalid requests to {{ site }}.{% endtrans %} ## {% trans %}Step 5: Using the Access Token{% endtrans %} {% trans site='SITE_NAME' | app_config %}To use the access token, include the following header in subsequent API requests to {{ site }}: `Authorization: Bearer access_token_goes_here`{% endtrans %} {% trans %}Python example, presuming that the application has obtained a valid `read` authorization:{% endtrans %} 
	import requests
	import pprint

	headers={"Authorization": "Bearer " + access_token,
			 "User-Agent": "Porpl Reader v1 by @captainmeta4"}
	url="https://ruqqus.com/api/v2/me/submissions"

	r=requests.get(url, headers=headers)

	pprint.pprint(r.json())
{% trans %}The expected result of this would be a large JSON representation of the submissions that make up the user's personal front page.{% endtrans %} {% trans %}For more endpoints, see documentation [here](/help/docs){% endtrans %} ## {% trans %}Step 6: Maintain Access{% endtrans %} {% trans %}Access tokens expire one hour after they are issued. To maintain ongoing access, you will need to use the refresh token to obtain a new access token.{% endtrans %} {% trans %}Make a POST request to `https://ruqqus.com/oauth/grant` with the following form parameters:{% endtrans %} * {% trans %}`client_id` - Your application's Client ID{% endtrans %} * {% trans %}`client_secret` - Your application's Client Secret{% endtrans %} * {# Translators: the word in quotes is a value the application sends as it is: keep it in English. #}{% trans %}`grant_type` - set to the word "refresh"{% endtrans %} * {% trans %}`refresh_token` - the refresh token which you obtained during Step 3{% endtrans %} {% trans %}Python example:{% endtrans %}

	import pprint

	headers={"User-Agent": "Porpl Reader v1 by @captainmeta4"}
	url="https://ruqqus.com/oauth/grant"
	data={"client_id": my_client_id,
		  "client_secret": my_client_secret,
		  "grant_type": "refresh",
		  "refresh_token": my_users_refresh_token
		  }

	r=requests.post(url, headers=headers, data=data)
