{# The names a co-authored post carries next to its author's (helpers/coauthors.py). coauthor_line(p, v, dot): " · with " for a post whose co-authors accepted, nothing for any other post. Names are links; a name the viewer's word filter hides is left out. `dot` false drops the leading dot, for the bar at the top of a post page. A collaborative post can have up to 50 authors: after five names the line says "and N others", linking to who wrote what (routes/collab.py). #} {% macro coauthor_line(p, v, dot=true) %} {%- set people = coauthors_of(p, v) -%} {%- if people -%} {%- set names %}{% for u in people[:5] %}{{ u.shown_name }}{{ handle_tag(u) }}{% if not loop.last %}, {% endif %}{% endfor %}{% endset -%} {{ ' · ' if dot else '' }} {%- if people | length > 5 -%} {#- Translators: beside a post's author, its co-authors: names is the first five, linked; num is how many more there are -#} {{ ngettext('with %(names)s and %(num)s other', 'with %(names)s and %(num)s others', people | length - 5, names=names, url="/post/" ~ p.base36id ~ "/written_by") }} {%- else -%} {#- Translators: beside a post's author, its co-authors: names is their names, linked -#} {{ _("with %(names)s", names=names) }} {%- endif -%} {%- endif -%} {% endmacro %}
